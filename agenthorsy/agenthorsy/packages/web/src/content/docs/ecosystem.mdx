Want to add your AgentHorsy related project to this list? Submit a PR.

You can also check out [awesome-opencode](https://github.com/awesome-opencode/awesome-opencode) and [opencode.cafe](https://agenthorsy.cafe), a community that aggregates the ecosystem and community.
